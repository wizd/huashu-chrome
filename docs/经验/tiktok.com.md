# TikTok（www.tiktok.com / TikTok Studio）

以下据 AiToEarn 开源代码整理（2026-11），未在页面实测；与现场不符以现场为准，验证后改写。

## 登录与账号确认

- 以 `@username` 为准：主页 `www.tiktok.com/@<username>`，或 Studio 左上角头像旁的名字。显示名可能重名，不能用来确认账号。
- 账号层能看到的数字：粉丝、关注、获赞、视频数。

## 发布

- 入口：TikTok Studio 的上传页（`www.tiktok.com/tiktokstudio/upload`，以现场为准）。有两种形态：视频，或图文（照片轮播）。
- 视频：一条，mp4/mov/webm，≤4GB，3 秒–10 分钟，最大分辨率 1080×1920 或 1920×1080。
- 时长上限因账号而异。平台按账号给出「最长可发时长」，超出会被拒，以上传页的提示为准。
- 图文：2–35 张，单张不能发；jpg/jpeg/webp（不收 png），每张 ≤20MB，每边 ≥360px；可选一张作封面（默认第 1 张）；可开「自动配乐」。
- 文字：说明 ≤2200 字（含 #话题、@提及）。视频的标题和正文合并成一段说明；图文有单独的标题和描述。
- 「谁可以观看」必选：所有人（公开）、互关好友（朋友）、关注者、仅自己。
- 「谁可以观看」的可选项因账号而异，只能从页面给出的项里选。AiToEarn 不给默认值，必须明确选择。
- 「允许用户」：评论、合拍、拼接。图文只有评论。账号设置里已关闭的项在这里灰掉，不能打开。
- 「披露视频」（商业内容）开关：打开后至少选一项。「您的品牌」会被标记为推广内容；「品牌内容」（推广第三方）会被标记为付费合作。
- 选了「品牌内容」后，可见性不能设为「仅自己」。
- 发布即表示同意音乐使用确认，选了「品牌内容」时还同意品牌内容政策。照实披露，不能为了过表单乱选。
- AI 生成内容声明（is_aigc）：内容是 AI 生成的就要开启。
- AiToEarn 不用平台的定时功能。Studio 上传页如果有「定时发布」，以现场为准。

## 成功判定与链接

- 发布是异步的，状态依次为：处理上传中、处理下载中、发到收件箱（草稿收件箱，需本人在 App 内确认）、发布完成、失败。
- 前端提示「发布后可能需要几分钟处理，才会显示在个人主页上」。不能把「点了发布」当作成功。
- 判定成功：在 Studio「帖子」列表或主页上找到新作品，并拿到作品 ID。
- 设为「仅自己」时，发布完成也可能拿不到公开链接，属正常，到 Studio 里核对即可。
- 链接格式：视频 `www.tiktok.com/@<username>/video/<id>`，图文 `…/@<username>/photo/<id>`。
- 短链 `vm.tiktok.com` 和 `vt.tiktok.com` 要先打开，跳转后才能拿到 ID。
- 发布后不能编辑（AiToEarn 不支持更新）。

## 作品与数据

- 单条作品：播放（view）、点赞、评论、分享，加上创建时间、时长、封面、说明。
- 在 Studio 的帖子列表或分析页读取，以页面指标名为准。

## 互动

- AiToEarn 没有 TikTok 的评论、点赞或关注功能，代码里查不到这些操作在页面上的位置，需现场摸索后补记。

## 坑

- 图文只放 1 张会被拒；png 不收，要转成 jpg。
- 「仅自己」与「品牌内容」冲突。
- 「允许合拍/拼接」灰掉不是页面坏了，是账号设置关了这两项。
- 发布可能卡在「发到收件箱」：TikTok 在等本人在手机 App 里确认，网页端等不出结果，要告知用户。
