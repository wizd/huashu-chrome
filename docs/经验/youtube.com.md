# YouTube Studio（studio.youtube.com）

依据2026-09-18本机实测整理。步骤会受账号资格、界面版本和视频类型影响。

## 注入失败时换工具

本轮`eval`被Trusted Types限制，简单表达式也失败。遇到同样错误时用`snapshot`、`query`、`click`、`type`或`act.find`，不反复换表达式重试。不要把一次环境结果写成所有版本永远不可用。

## 上传、草稿与排定

- 上传对话框打开后先找file input，用`upload`注入；点「选择文件」可能打开扩展无法操作的系统文件框。
- 每走完一步重新snapshot。按钮不可用时，先检查前面步骤是否有未完成项，不能只等视频处理进度。
- 本轮「预定」未解锁与创收设置、自评步骤未完成有关。是否创收、自评选项必须依据用户决定和实际内容填写；不能机械选择「以上都没有」。并非每个账号都出现相同步骤。
- 草稿从内容列表的「编辑草稿／继续上传」恢复。本轮直接访问普通视频编辑链接会失败。
- 定时时间要读取页面显示的时区，不能假设它等于电脑时区。
- 保存后在Studio内容列表核对排定状态与日期时间。主站是否登录和公开播放页能否打开，不能单独证明Studio里的定时设置成功或失败。

## 规则摘要（AiToEarn 代码）

以下据 AiToEarn 开源代码整理（2026-11），未在页面实测；与现场不符以现场为准，验证后改写。

### 登录与账号确认

- 一个 Google 账号可有多个频道。发布前在 Studio 左上头像或右上「切换账号」核对频道名；以频道 ID（`UC…`，Studio 地址 `/channel/UC…/`）为准，不以显示名为准。
- AiToEarn 上传后会再查一次视频的所属频道，不一致就判失败。网页上同样做：成功后在该频道的「内容」列表里找到这条视频。

### 发布字段与限制

- 只发视频，一次一条。格式 mp4/mov/avi/wmv/flv/mkv，≤256GB，≤12 小时。建议 16:9（1920×1080）或 9:16（1080×1920），其他比例只给警告。
- 标题必填，≤100 字；说明必填（AiToEarn 前端强制），≤5000 字。
- 标签：正文里的 #话题 被抽成标签，标签合计 ≤500 字符。网页上填在「显示更多 → 标签」。
- 类别必填。下拉框只列当前频道和地区可用的项。选了不可用的类别，平台报 invalidCategoryId。
- 其他选项及默认值：公开范围默认公开；许可默认「标准 YouTube 许可」（另一项是知识共享）；允许嵌入默认开；通知订阅者在 AiToEarn 前端默认开（后端默认关），按用户意愿设置；面向儿童默认「否」；另有「包含经过修改或合成的内容」。面向儿童和合成内容按实际内容填。
- 缩略图可选。设置失败不影响发布，所以要在页面上确认缩略图已经替换。
- 定时：要先设为「私享」，再填发布时间；AiToEarn 只在私享状态下才接受定时。

### 成功判定与链接

- 视频 ID 是 11 位字符。帖子链接：`https://www.youtube.com/watch?v=<id>`。
- 能解析出 ID 的链接形式：`youtu.be/<id>`、`/shorts/<id>`、`/embed/<id>`、`/live/<id>`、`/v/<id>`、`m.youtube.com`。
- 已发布的视频可改标题、说明、标签、公开范围、类别、许可、嵌入、儿童和合成内容；不能换视频文件。

### 作品与数据

- 频道层：订阅人数、视频数、总观看次数。
- 单条视频：观看次数、顶、评论数，加上发布时间。这些在 Studio「内容」列表的行内或视频的「数据分析」里。
- 内容列表按频道列出视频，每页最多 50 条，需翻页读完。

### 互动

- 评论按顶层评论列出，每条带作者频道 ID、顶数和回复数。能做的操作：发顶层评论、回复评论、删除评论。删除不可撤销，要先确认。
- 代码里没有点赞或订阅他人的功能。

### 坑

- 定时发布而不设私享，会被拒（见上文）。
- 类别、儿童内容和合成内容都是声明，不能为了过表单随手勾选。
