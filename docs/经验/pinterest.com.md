# Pinterest（www.pinterest.com）

以下据 AiToEarn 开源代码整理（2026-11），未在页面实测；与现场不符以现场为准，验证后改写。

## 登录与账号确认

- 以用户名为准：主页 `www.pinterest.com/<username>/`，右上头像菜单里能看到用户名。一个人可能同时有个人号和商业号，用头像菜单切换后要再核对一次。
- 账号层数字：粉丝、关注、月浏览量（monthly views）、Pin 数。

## 发布（创建 Pin）

- 入口：顶部「创建 → 创建 Pin」，或 `www.pinterest.com/pin-creation-tool/`（以现场为准）。
- 每个 Pin 只能放 1 张图或 1 段视频，不能混放，不能多图。
- 图片：bmp/jpg/png/tiff/webp，≤20MB。
- 视频：mp4/m4v/mov，≤2GB，4 秒–15 分钟（AiToEarn 后端按 ≤5 分钟卡，以页面为准）。视频必须有封面，在页面上选帧或上传封面图。
- 标题必填，≤100 字。
- 描述 ≤800 字。没有话题字段，# 只是普通文字。
- 画板必选。画板下拉支持搜索，也可以当场新建画板；新建时可设为公开或秘密。
- 可选：目标链接（点 Pin 后跳转的 URL）；替代文本（≤500 字）。
- AiToEarn 不用定时；网页创建页如果有「稍后发布」，以现场为准。

## 成功判定与链接

- 视频 Pin 要先上传处理，处理成功后才发出，最多等约 5 分钟。处理失败要重新上传。
- 链接格式：`www.pinterest.com/pin/<id>/`。刚发出时可能暂时打不开，过一会儿再到主页的「已创建」里核对。
- 短链 `pin.it/<code>` 要先打开，跳转后才能拿到 ID。
- 已发布的 Pin 可编辑标题、描述、链接和画板（在 Pin 详情页点「…」→ 编辑）。

## 作品与数据

- 单个 Pin 的指标：展示（impressions）、保存（saves）、Pin 点击、外链点击（outbound clicks）、视频播放。
- AiToEarn 把 Pin 点击和外链点击合成一项「点击」；在页面上读时两项分开记。
- 数据按天给出。在 Pin 详情页的统计入口或「数据分析」里看，以现场为准。

## 画板

- 画板有三种隐私级别：公开、受保护、秘密。
- 画板能新建、改名、改描述、删除。删除画板会连同其中所有 Pin 一起删掉，不可恢复，必须先征得用户确认。

## 互动与采集

- AiToEarn 没有 Pinterest 的评论、点赞或关注功能，这些页面位置需现场确认。
- 采集时注意：作品链接只认 `pinterest.com`（含各国子域名，如 `xx.pinterest.com`）下的 `/pin/<id>`。

## 坑

- 视频没有封面就发不出。
- 没选画板，创建按钮不可用。
- 一个 Pin 只能有 1 个媒体；多图要拆成多个 Pin，或改用平台的轮播或拼贴功能（以现场为准）。
